`candidatePrimary`：候选值必须由 P1.7 Runtime 对 exact Roadmap resource 执行 refresh，写入
P1.5 SQLite normalization ledger，再由 Facade 的只读端口读取；任何 missing、stale、corrupt、
identity drift、comparison error 或 unexplained difference 都显式回退 legacy，其他五路 Facade
保持不变。

## 本 PR 必须交付

1. **Roadmap-only candidate mode**
   - `OPCB_ROADMAP_FACADE_MODE=candidate-primary` 才允许候选成为返回值。
   - 缺失、未知或其他字符串保持 `legacyOnly`；默认值不得改变。
   - mode、最后实际 read source、fallback reason 与 comparison report 必须可测试、可审计。
2. **Durable candidate source**
   - 新增 exact `NormalizedResourceKey(projectID: opcb, resource: roadmap-cache/roadmaps.json)`。
   - `SQLiteNormalizationStore<RoadmapProjection>` 使用独立私有数据库与稳定 value type。
   - Runtime route 必须先 commit `.begin`，再读取 v1 cache adapter，最后 commit observation。
   - Facade 只能通过 read-only closure/port 读取 materialized projection，不得持有 SQLite
     mutation、runtime schedule 或 provider 权限。
3. **Fail-closed selection gate**
   - candidate 只有在 exact resource、可解码 stage、`live`／`cached` freshness、无 active
     refresh、无 unexplained difference 且业务字段等价时才可返回。
   - runtime generation 与 legacy cache timestamp generation 的预期差异必须单独记录理由；
     不允许把业务字段、freshness、error 或 timeline drift 加入允许列表。
   - candidate missing/stale/unreachable/partial/unknown、store open/read failure、schema mismatch、
     comparison error、conversion error 或 unexplained difference 一律返回 legacy，并记录 typed
     fallback；不得补空路线图或健康状态。
4. **刷新与 UI 边界**
   - 成功 live fetch 仍先保存兼容缓存，再由 Runtime normalize；UI 更新必须重新经过 Facade，
     使 candidate-primary 的返回值确实驱动 Roadmap UI。
   - legacyOnly/shadow 保持原行为；切回默认 mode 并重启即恢复纯旧权威路径。
   - 30 分钟 schedule、RoadmapStore 写入、Dashboard、偏好、外部链接和错误提示不改语义。
5. **验证与架构守卫**
   - 覆盖 candidate success、missing/stale/corrupt/drift fallback、unknown mode、restart/reopen、
     exact resource isolation 和 rollback-to-legacy。
   - 证明只有 Roadmap enum 出现 candidate-primary；其他 Facade mode 不得改变。
   - 完整 `swift test`、`test-native.sh`、exact-head SourceBinding、`diff --check`、merge-tree 与 CI。

## 明确不做

- 不删除 RoadmapStore、legacy cache、legacy decoder 或回退路径。
- 不把任何其他 Facade 切到 candidate-primary。
- 不改 Roadmap GitHub provider、刷新频率、UI 设计、Registry 或命令路径。
- 不安装 App，不修改正式偏好，不启动 candidate process 覆盖正式进程，不部署环境。
- 不因 candidate missing/corrupt 而把 legacy failure 改写成空、成功或完成。

## 停止条件

- live main/head 漂移但没有重新验证；
- candidate 可以绕过 exact resource、durable projection 或 comparison gate；
- 回退需要 reset/rebase/覆盖受保护脏工作树；
- 为完成代码 PR 必须安装、部署、读取 secret 或接真实命令；
- 其他 Facade 或 UI 行为被顺带切换。
