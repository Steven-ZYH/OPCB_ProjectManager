## 一句话目标

建立一个单一、可取消、可重放、fail-closed 的 `ProjectControlRuntime` actor：它是 adapters、
business refresh schedules、in-flight refresh、durable normalization store、Policy Engine、
confirmation issuance/consumption、CommandBus journal 和 projection stream 的唯一 owner；
同时把 AppDelegate 的业务 Timer 与 repository refresh Set 迁出，但保持所有 Facade 仍为
`legacyOnly`/`shadow`，不在 P1.7 切生产读路径。

## 本 PR 必须交付

1. **ProjectControlRuntime 单一 actor**
   - 新建 `ProjectControlRuntime` package target；Domain/Store/Adapters 不反向依赖 Runtime。
   - actor 内拥有 schedule tasks、refresh leases、generation/correlation、cancellation、
     projection subscribers、policy/confirmation/command orchestration。
   - 不允许 AppDelegate、adapter callback、UI controller 或 side-effect executor 再维护同一
     resource 的第二份 in-flight/Timer authority。
2. **RefreshCoordinator 闭环**
   - exact `NormalizedResourceKey` 维度 claim；并发重复 refresh 返回 typed duplicate/in-flight。
   - generation 单调；先 durable `.begin`，再调用 exact adapter，最后 durable observation/failure。
   - cancellation、timeout、adapter throw 必须形成明确 failure 或 cancellation result；late callback
     不能覆盖新 generation。
   - projection 更新从 commit result 发布为 `AsyncStream`；订阅者只能读 value-free identity/
     freshness/generation 与 typed projection，不拥有 refresh 或 store mutation。
3. **统一业务调度**
   - actor 用 injected sleeper/clock/UUID source 管理 periodic task；同 schedule ID 只能有一个 owner。
   - start/stop/wake/manual trigger 可测试；stop 后不得继续回调，restart 不得形成双 loop。
   - 迁移 AppDelegate 的 GitHub snapshot、session activity、review-machine status、roadmap 四类
     Timer ownership；纯 UI animation timer 保留在 UI 层。
4. **Confirmation authority 与 durable replay**
   - 只允许对 `PolicyDecision.confirmationRequired` 发行 grant；issued/expires/time 全部注入。
   - durable journal 记录 token ID、command ID、requirement digest、issued/expires 与消费状态；
     forged/unknown/mismatch/future/expired/already-consumed token fail-closed。
   - issue/consume 必须幂等区分 exact retry 与 identity conflict；一次 token 只能 claim 一个命令。
   - 不存 secret、raw provider payload 或 arbitrary audit dictionary。
5. **CommandBus ownership**
   - 先读取 exact durable fact并运行 Policy Engine；没有 allow 不得 claim/execute。
   - allow 后在执行前原子 claim command+token；duplicate submission 不重复执行。
   - executor 是 typed injected port，必须接收 exact `CommandIntent`/idempotency identity；P1.7
     只用 fake/closed executor 验证，不接真实 merge/deploy/secret provider。
   - 明确 claim-before-execute crash window 和 recovery 状态；未知 pending 不得自动重放副作用。
6. **架构、隐私和回归**
   - 覆盖 concurrent refresh、cancel/restart、late observation、schedule double-start、stream order、
     token forge/replay/conflict/expiry、command duplicate/failure 与 action-scope isolation。
   - SQLite durable journal reopen/concurrent consumer/permission/corruption fail-closed。
   - Runtime 可依赖 Domain/Store/Adapters；Domain 保持无 Runtime/SQLite/provider/timer/UI。
   - 完整 `swift test`、`test-native.sh`、source binding、codesign、diff-check、merge-tree 和 CircleCI。

## AppDelegate 迁移边界

- P1.7 只迁移业务 scheduling/in-flight ownership；legacy facade 的数据展示行为保持不变。
- AppDelegate 可保留 MainActor UI 更新和 callback bridge，但不能保留对应 Timer 或 repository
  in-flight Set；bridge 必须把 lifecycle 交回 Runtime actor。
- `sessionActivityRefreshInProgress` 等非 repository 单例锁，若由同一 schedule 管理，也应迁入
  actor 或替换为 exact runtime lease；不得只改变量名形成双 owner。
- P1.8 之前所有 read facade mode 仍不得进入 `candidatePrimary`。

## 明确不做

- 不接真实 GitHub merge/push、deployment、rollback、secret provider 或 shell/SSH executor。
- 不读取或持久化 secret 值，不生成需要生产密钥的签名方案。
- 不新增 Registry 正式配置或 UI 功能，不切 Facade mode，不安装 App，不部署环境。
- 不把 UI animation timer 纳入 business runtime。
- 不把 crash-window pending 自动解释为 safe-to-retry；恢复策略必须显式、fail-closed。

## 停止条件

- 需要 reset/rebase/覆盖受保护脏工作树；
- 出现两个 timer、两个 in-flight Set、两个 confirmation consumer 或两个 command owner；
- adapter/command completion 可绕过 generation/token/command claim；
- missing/unknown/corrupt journal 被当作未消费或可执行；
- 为完成 P1.7 必须接真实 provider、读取 secret、切 Facade、安装或部署；
- live main/head 漂移但没有重跑对应证据。
