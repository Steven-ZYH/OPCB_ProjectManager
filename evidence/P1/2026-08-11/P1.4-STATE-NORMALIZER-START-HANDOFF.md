## 一句话目标

在不新增 timer、UI 或外部写能力的前提下，把现有 `Observed<T>`／
`ObservationMerger` 扩成按资源隔离、带 monotonic generation 与
expected-generation CAS 的纯 State Normalizer，使晚到、重复、冲突、失败保留和
过期转换都可确定测试。

## 本 PR 必须交付

1. 定义稳定的 normalized resource key，至少绑定 `projectID + ResourceRef`，不得用
   本机绝对路径或 UI 文案作为身份。
2. 定义 refresh/observation envelope：resource、generation、request/correlation ID、
   source、startedAt/observedAt/expiresAt、value 或 typed failure。
3. 实现纯 State Normalizer reducer：
   - `begin`：只为目标 generation 进入 fetching，不清空上一有效值；
   - `accept`：仅 expected generation 可更新；
   - `fail`：保留上一有效值并显式成为 stale/partial/unreachable；
   - `expire`：只基于注入 clock 改 freshness，不发明新 evidence；
   - 输出 applied/duplicate/droppedLate/conflict/rejectedInvalid 的 typed decision。
4. 建立 in-memory projection store/test double，提供 expected-generation CAS；该实现
   不是长期事实源，不引入 SQLite。
5. 扩展只读 Adapter 边界，使 observation 明确携带 resource/generation/correlation，
   但不迁移真实 GitHub、Session、Roadmap 或审核机客户端。
6. 添加竞态与反例测试，并让 Swift package XCTest 继续由 `test-native.sh`/CircleCI
   执行。
7. 记录下一阶段 P1.5 所需的 event/projection persistence 接口，不用空数据库或
   placeholder migration 假装完成。

## 关键测试矩阵

- generation 2 先返回后，generation 1 永远不能覆盖。
- 相同 generation/observedAt 的不同值是 conflict，不按“最后写入”取胜。
- 完全相同 observation 是 duplicate，不重复写 projection。
- begin generation 2 时保留 generation 1 的值；失败后仍保留旧值并带错误状态。
- 一个资源成功不能把同项目其他 unknown/unreachable 资源补成健康。
- expiresAt 前后由注入 clock 确定转换；读取本身不改变 source 或 generation。
- project/resource key 不同的观察互不污染。
- invalid/unsupported/missing-evidence 与 provider timeout/offline 保持不同分类。
- CAS 失败、late drop 与 conflict 都产生可审计但不含 secret 的 typed decision。
- 完整 `swift test`、`test-native.sh`、bundle source binding、codesign 保持通过。
