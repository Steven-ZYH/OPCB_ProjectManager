## 已关闭能力

- `ProjectControlStore` 内建立可审查的 `CSQLite` system-library 边界；Domain 继续无
  SQLite、AppKit、provider、timer、`Process` 或 shell 依赖。
- schema v1 建立 metadata、append-only ledger、materialized projection 和 cursor；
  schema v2 增加 checkpoint projection/cursor，并支持 v1→v2 单事务 migration。
- event payload、decision payload、value discriminator 和 codec version 分层；未来 schema、
  类型错配、identity 漂移或损坏记录均拒绝打开／重放。
- event append、typed decision、expected-generation projection CAS 和 cursor 在一个
  `BEGIN IMMEDIATE`／`synchronous=FULL` transaction 内提交。
- event UUID 与 correlation identity 重试幂等；相同 identity 的不同 payload fail-closed。
- full/checkpoint rebuild 只使用既有 `StateNormalizer`；完成全部验证前不替换有效
  materialized projection。
- checkpoint 不只验证内部自洽，还必须等于 ledger 到该位置的确定性重放结果。
- backup candidate 在原子替换前完成 integrity、typed ledger、decision 和 materialized
  state 验证；失败保留唯一有效库。
- `DurableProjectionReading.projection(for:)` 已作为 P1.6 的只读消费端口留在 main；它
  不暴露 SQLite、mutation、provider refresh、timer 或 command execution。
