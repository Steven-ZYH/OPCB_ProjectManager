## 实现证据

- `ProjectControlStore` 新增 `CSQLite` system-library 边界；`ProjectControlDomain`
  继续不依赖 SQLite、AppKit、provider、timer、`Process` 或 shell。
- schema v1 建立 metadata、append-only ledger、materialized projection 和
  last-applied cursor；schema v2 增加 checkpoint projection/cursor，v1→v2 在单事务迁移。
- 数据库绑定稳定 `value_type`、正整数 `codec_version` 与 event payload version 1；
  类型、codec、未来 schema、损坏 record 或 typed-column 漂移均 fail-closed。
- event UUID 与 `(canonical resource, generation, correlation, phase)` 重试幂等；
  相同 identity 的不同 payload 拒绝写入。
- 每次提交在 `BEGIN IMMEDIATE` / `synchronous=FULL` 内完成 event append、typed
  decision、expected-generation projection CAS 和 cursor 更新。append 后及 projection
  写入后的故障注入均证明全事务回滚。
- full/checkpoint rebuild 只调用既有 `StateNormalizer`，逐条核对持久化 decision；
  重放完成前不替换有效 projection。中断或损坏不会覆盖唯一有效状态。
- checkpoint 接受前额外从 ledger position 0 重放到 checkpoint position，并要求
  snapshot projection、cursor 与 exact resource identity 全部等于 reducer 的确定性结果；
  自洽但与 ledger 不一致的有效 JSON checkpoint 会在删除当前 projection 前失败。
- backup 使用 SQLite online backup 到私有候选库，完成 integrity、typed ledger、
  reducer decision 和 materialized state 验证后原子替换；restore 保留 rollback copy。
- 数据库在 SQLite 首次打开前即创建为 `0600`；测试临时目录为 `0700`。
- value/provider failure 只进入受保护 `event_payload`；value-free
  `decision_payload` 未扩展 `AuditEvent.attributes`。
