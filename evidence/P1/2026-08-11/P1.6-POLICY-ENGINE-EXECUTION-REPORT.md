## 实现证据

- `ProjectControlDomain` 新增 typed `PolicyVersion`、`PolicyActor`、`CommandIntent`、
  `CommandAction`、action-specific facts、decision 和 confirmation contract。
- `PolicyEngine.evaluate` 是纯函数，仅使用显式 intent、fact、policy version、注入时间和
  optional confirmation；不读取网络、SQLite、环境变量、timer、UI 或 secret。
- merge、deploy、secret capability 三类 action/scope 独立建模；一种权限、事实或确认不能
  转移到另一种 action。merge 还精确绑定 repository、PR、head、base、approval、checks、
  unresolved threads 和 mergeability。
- deploy 精确绑定 environment、artifact、commit、risk、merge evidence 和 deploy authority；
  风险等级由 typed scope/fact 显式给出，不从环境名称推断。
- secret-use 只绑定 capability、actor、purpose 与 environment；没有 secret value 字段。
- 仅接受 exact resource 下类型正确、非未来、未过期的 live/cached durable fact；missing、
  fetching、stale、partial、unreachable、unknown、错误 sibling、错误 kind 或 scope mismatch
  全部拒绝。
- 通过事实只能进入 `confirmationRequired`。只有精确、未过期的 grant 才进入 `allowed`；
  grant 绑定 command/action/risk/actor/project/resource/policy version 以及 intent/fact digest。
- confirmation requirement 的稳定时间来自 `intent.requestedAt`，因此同一 grant 在过期前
  的纯重评估保持确定；签发、签名、持久化、一次性消费与 replay protection 属于 P1.7。
- decision 与 confirmation 只保留摘要和必要 scope，不暴露 provider failure、raw head/base、
  secret 或其他值载荷。
- `DurablePolicyFactReader` 只通过 `DurableProjectionReading.projection(for:)` 读取一个
  exact `NormalizedResourceKey`；不持有 SQLite 写权限、runtime、timer 或 command 能力。
- architecture guard 禁止 Policy Engine 引入 AppKit、CSQLite、SQLite、URLSession、Process、
  Timer、DispatchSource、FileManager、UserDefaults、sqlite3、shell 或 GitHub provider。
