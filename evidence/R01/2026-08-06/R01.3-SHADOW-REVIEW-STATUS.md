## 结论

- 第三个 Legacy Facade 只读切片：**通过**。

## 比较范围

1. 完整原始 JSON：machine、worker、codex、quota、news 与时间字段；
2. 300 秒 freshness 与 cached/stale 状态；
3. worker queue、active job、phase 与 Codex process 状态；
4. thermal、temperature/power availability；
5. quota availability、remaining percent、限制最紧窗口；
6. 官方 quota reset prediction 优先级、epoch、window 与 source；
7. news status、latest 与 quota signal 是否存在；
8. source、observedAt、expiresAt、generation、freshness 与 error。

新 Adapter 对非 v1 schema fail-closed；缺失文件、无证据、损坏 JSON 与不支持版本不会合并成同一种“空状态”。
