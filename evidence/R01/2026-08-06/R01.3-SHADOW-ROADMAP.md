## 数据流与边界

1. `RoadmapLegacyFacade` 调用旧 `RoadmapStore.load()`，保留原返回值。
2. shadow 模式下，`RoadmapCacheV1Adapter` 独立读取同一 `roadmaps.json`。
3. 两侧映射为 `Observed<RoadmapProjection>`，保留 source、observedAt、expiresAt、generation、freshness 与 error。
4. `ShadowComparator` 逐字段比较文档、条目及观察元数据，并生成 verification 类 `AuditEvent`。
5. 无论比较结果如何，Facade 均把旧快照返回 App；比较器异常单独记录为 `comparisonError`，不隐藏成“等价”。

明确未改动：路线图 GitHub fetch、30 分钟刷新阈值、旧 Store 写入、Dashboard 渲染、可见性偏好、PR 跳转与外部命令路径。
