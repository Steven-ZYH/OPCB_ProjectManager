## 比较范围

新 Adapter 独立读取与旧 `SnapshotStore` 相同的 project-specific JSON，并比较：

1. 全部原始 JSON 叶子字段、对象/数组类型与元素数量；
2. `null`、缺失、字符串、布尔与数字的类型差异；
3. 每个 PR 的 current-head review decision、peer approval、CI 通过/运行/失败/跳过数量；
4. `reviewGateSyncPending`、`isAwaitingPeerApproval`、当前用户待审状态与遥测摘要；
5. ACTION/READY/REVIEW/RUNNING/DRAFT 分组；
6. 显式或 fallback action reason/next step；
7. reviewCount、自动部署失败数和菜单徽标数；
8. source、observedAt、expiresAt、generation、freshness 与 error。

未知候选字段不会被忽略；重复 PR number、repository 错配和重复允许差异规则均 fail-closed。
